# rel-038 ceremony — the ready kit

**Frozen 2026-09-17, BEFORE any leg runs.** Nothing below is tuned to the
round it judges; that is the rule the margins exist under.

## The arms

| | |
|---|---|
| rc | **0.38.0**, packed from `fix/reg1-deepseek-window` (15 tarballs), installed into a clean prefix |
| ctl | **0.37.0**, the PUBLISHED release, installed into a separate clean prefix |
| invocation | absolute path, both arms |
| per-leg gate | each leg verifies the version it ACTUALLY ran |

That last line is not ceremony. Both arms reported 0.37.0 during
preparation — the tree had not been bumped — and a ceremony run that way
compares a build against itself and reports perfect agreement. The check
has now caught this class three times, once when `npx -y pkg@version`
resolved through a local node_modules link and the control leg ran the
release candidate under the ctl label.

## Design

12 interleaved rc/ctl pairs, T5, 24 legs. Interleaved rather than
batched because the pairing is what cancels common-mode provider drift —
running the arms as two blocks would reintroduce the confound the method
exists to remove, which is also why the legs are not parallelised for
speed.

## Criteria — `bm1-a1`, read from `paired-compare.mjs`, not from memory

| | |
|---|---|
| verify | **100%** |
| median(d_cost), cost-weighted | **≤ +20%** |
| median(d_wall) | **≤ +25%** |
| a single pair > +50% | an **ANOMALY NOTE**, never a block |

`bm1-a1` is the default since the rel-030 freeze; `bm1-frozen`'s +6% is
RETIRED and is kept only for re-reading old records. CLAUDE.md still
quotes the superseded +6% — a documentation gap, and this round runs
under +20%. A ceremony was once run under the retired bar hours after
that retirement was stated; naming it here is how that does not repeat.

## Causal relevance

The change surface is tool schemas and the search corpus — a
prompt/tool-schema round. Under BM-1 §3 the request-byte gates AND the
paired bench BLOCK.

## What a failure means

A regression out of band on the EXPENSIVE side, or any failed verify, is
blocker-class: a hard stop before the release, awaiting adjudication.
Movement out on the CHEAP side with every leg verify=pass is
improvement-class and ships carrying "proposed, for the reviewer" (the
S1-1 directional clause).

## What this round cannot say

n=12. The programme's paired cost measurements at this size have a
per-pair spread near 30 points and cannot resolve an effect under about
20%. Two ceremonies of the same change once disagreed by 22 points. The
verdict is a REGRESSION GATE, not a measurement of improvement, and no
cost number from it will be claimed as a win.
