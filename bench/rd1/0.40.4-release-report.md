## What is in it

| PR | what changed |
|---|---|
| profile headers | a model profile names the headers its endpoint needs (`"headers"`); `{session}` in a value becomes the kiso session's id, so one conversation keeps one id across `/model` and `/resume` and two never share one; credential and framing headers are refused by name (a key never lives in the config file); the three adapters send them (the Responses adapter merges its own credential over them). A gateway that refuses requests without its session header is now reached directly, without a local forwarder |
