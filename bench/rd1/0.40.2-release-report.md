## Dogfood (the release rule: both passes before APPROVED)

### The agent's pass (published 0.40.2, a real model)

- **Session** `dogfood-0402`, profile `ds` (`deepseek-flash` at
  api.deepseek.com, the key injected into the one process by
  `bench/cred-exec.sh`), `--mode bypass`, workspace
  `/private/tmp/dogfood-0402`, log at
  `~/.kiso/projects/-private-tmp-dogfood-0402/dogfood-0402.jsonl`.
- **The task:** a six-module fixture whose `npm test` failed; "read EVERY
  file under src/ and test/, find the bug, fix it with the smallest
  change, re-run npm test until it passes, state the diff". The window was
  STATED at 20,000 (`KISO_CONTEXT_WINDOW`) so the compaction tiers would
  be reached by a small task — the surface this release changes.
- **The outcome:** 27 tool calls over 18 requests; `npm test` 2/2, exit 0;
  1 m 23 s, `fresh 12.5k out 8k · cache 95%`. The model found the planted
  bug (`median` returned `s[mid]` for both parities → the mean of the
  middle two) AND a defect the worker had not planted: the fixture's
  `node --test test/` does not run on this Node 22 (`MODULE_NOT_FOUND`) —
  the worker's own "0 pass / 1 fail" was that, not the bug. It changed the
  script to `node --test test/*.test.js` and said why. Both diffs are
  right.
- **The compaction surface, read from the log and the trace:** the soft
  tier fired three times at phase ends (`phase:check`, in-band), and all
  three checkpoints were DISCARDED by the shrink invariant — each would
  have grown the context (~6.3k → ~7.6k, ~6.6k → ~7.9k, ~6.9k → ~8.1k,
  writing ~1.4–1.5k). The model had read all eight files (package.json,
  six modules, the test) in ONE round (round 2, eight parallel calls), a
  round the boundary cannot split, so a fire could cover almost nothing.
  0.40.1 would have appended all three. After the third, the breaker
  stood, and no further summary was paid for. 0 summaries kept, 0
  stacked; the notice line appeared each time; the run completed.
- **Finding A2-F1 (next round, not a blocker):** a discarded checkpoint
  was still PAID for — an in-band call carrying the whole context. The
  coverable range can be estimated BEFORE the call (the projection with
  the boundary applied and an empty summary); a fire that could not
  remove even a minimal summary's worth should not call the model.
  Measured here: three calls for ~0.1k of coverable text each.
