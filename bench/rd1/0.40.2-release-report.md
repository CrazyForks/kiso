# 0.40.2 — release report (RELEASE CANDIDATE)

A patch for a P0 in the published 0.40.1, and one P1. Both review PRs are
merged on `main` (#100, #101), each with the required `check` green. The
owner's word, in the worker's session on 2026-09-23: "merge, then
release". This report is updated to PUBLISHED when the tag is on `main`
and the registry answers 0.40.2 for all 15 packages.

## What is in it

| PR | finding | what changed |
|---|---|---|
| #100 | the summary stacking (P0) — ADR-0055 Amendment 2 | a checkpoint REPLACES every earlier one: ranges nest and ONE summary projects; a fire must remove at least what it writes, or it is discarded and counts toward the breaker (now at every tier but overflow); a context overflow is recognised by its text whatever the status, and — past a STATED window — by kiso's own measure; the emergency reserve assumes 131,072 output tokens when no one states the maximum; an assumed window is said at build; the status row names the model without its vendor prefix |
| #101 | esc in a committed round leaves a dangling tool call (P1) — ADR-0047 Amendment 3 | a committed call with neither a started event nor a result, in a run that ended aborted, gets ONE durable "aborted before execution" result at the next run or /compact, riding the run that owns it |

### The P0, in the owner's numbers

In 0.40.1 an in-band checkpoint restated the whole task while the
projection kept every earlier summary beside it. Four of the owner's
sessions stacked 1.48M–3.34M characters of summaries; once they passed the
firing tier every round compacted again, and the context GREW by ~13K per
compaction until the provider refused (1,047,981 tokens, then a 500
retried ten times). Replayed through the 0.40.2 projection (sizes only,
`scripts/replay-projection.mjs`), the four sessions recover with no
migration:

| session | summary messages | projected estimate |
|---|---|---|
| flowpix2 `2026-09-21T04-41-27-d7aa` | 70 → 1 | 872,035 → 43,722 |
| flowpix2 `2026-09-22T07-47-36-d4fc` | 66 → 1 | 873,599 → 31,505 |
| uooki `2026-09-21T02-26-26-d2ce` | 68 → 1 | 855,818 → 51,024 |
| reelfo `2026-09-21T04-45-25-a9ea` | 40 → 1 | 412,766 → 52,258 |

The one session #101 heals (`2026-09-22T01-58-27-0027`, five consecutive
400s) is the only one of 119 on the owner's disk with a stranded call.
