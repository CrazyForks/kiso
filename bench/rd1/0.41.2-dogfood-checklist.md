# 0.41.2 — dogfood checklist (for the owner's manual pass)

The release rule: after the publish, the agent runs one real-model session
on a real task, and the owner runs an independent pass. Both go into the
record before 0.41.2 is APPROVED.

```
npm install -g @vincemakes/kiso-code@0.41.2
kiso --version        # 0.41.2
```

## A. Nothing changed for kiso-code — and that is the check

0.41.2 touches `packages/server` only; kiso-code imports none of it. A
normal session behaves as 0.41.1 did; `/status` ends with `version 0.41.2`.

## B. The service (only if you want to look)

`npm view @vincemakes/kiso-server version` → 0.41.2. A session id that
starts with `_` or `-` is routed; `hooks.onSettled` exists.

## C. What would be a finding

- A session that behaves differently from 0.41.1 on the same task.
