# 0.42.3 — dogfood checklist (for the owner's manual pass)

The release rule: after the publish, the agent runs one real-model session
on a real task, and the owner runs an independent pass. Both go into the
record before 0.42.3 is APPROVED.

```
npm install -g @vincemakes/kiso-code@0.42.3
kiso --version        # 0.42.3
```

## A. Nothing changed in code — and that is the check

0.42.3 changes comments and documentation only. A normal session behaves
as 0.42.2 did; `/status` ends with `version 0.42.3`.

## B. What would be a finding

- Any behaviour that differs from 0.42.2 on the same task.
