## What is in it

| round | PR | what changed |
|---|---|---|
| R1 | #120 → #125 | `AgentDefinition.toolRules`: the tool table's vocabulary rows ("read files with read_file, never shell cat/head/tail", …) were a runtime constant keyed by tool NAME and reached every host whose tool shared a name — a product with no shell was told never to shell cat. The rows are the product's now (kiso-code's `CODING_TOOL_RULES` in `apps/cli/src/coding-prompt.ts`); the runtime keeps the mechanism. kiso-code's table is byte-identical to a fixture captured on the pre-R1 code. `makeAgent` moves out of `index.ts` as `createCodingAgent`, verbatim |
| R3 | #123 → #125 | `@vincemakes/kiso-server`: the hosted-session service — many durable sessions in one process, the one-run rule, observers with exact replay from a seq, approve / abort / resume routed to the right run, drain, close, boot-time open-run discovery. Control inversion: the product supplies the agent factory; no product noun inside; every run is the session's own `run()` / `resume()` |
| R4 | #124 → #125 | `@vincemakes/kiso-protocol` (zero dependencies): the wire contract — request envelopes, wire events as a PROJECTION of the durable stream (20 of 27 types, a per-type field allowlist, tool arguments sanitized; the classification is pinned total), the snapshot, one error shape, a version. `@vincemakes/kiso-server/http`: the HTTP + SSE transport — the routes both hosting products had written, framing and status codes decided once, `authorize` required |
| R5 | #125 | `@vincemakes/kiso-client`: the typed client over the wire, browser and Node, protocol-only; `events()` reconnects with `Last-Event-ID` and never yields a seq twice |

What each is for: uooki, reelfo and flowpix2 each wrote ~1,000 lines of
session-hosting and SSE code on top of the runtime; the R2 responsibility
map (kiso-doc `host-responsibility-map-2026-09-23.md`) measured the
duplicate and R3–R5 are that layer, once. kiso-code does not use any of
the three packages.
