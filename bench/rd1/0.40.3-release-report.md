## What is in it

| PR | finding | what changed |
|---|---|---|
| #104 | DC-60 — empty session files | a session that never began leaves nothing on disk: a new session writes its revision 1 WITH its first durable event (still before it), and a start-up resume with nothing to recover starts no trace and writes no summary row. `kiso sessions --prune-empty` lists the ones earlier versions left (56 on the owner's disk); `--yes` moves them to the Trash, never deletes, and skips a session a live process holds |

| #106 | CW-1 — `ctx ?` whenever the address changes; the first-turn `miss 3k`; the forwarder label | the context window follows the MODEL, not the address: what you set → what this endpoint refused at (learned from its own refusal, kept in `~/.kiso/learned-windows.json`, only ever lowered) → the registry's row for this endpoint → for the profile's `upstream` → the model's own window (vendor prefix dropped, a dated alias applied, the smallest where rows disagree); `/status` and `/model` say which step answered; an unknown model falls back to 128K (was 200K).
