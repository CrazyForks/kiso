# 0.40.6 — dogfood checklist (for the owner's manual pass)

The release rule: after the publish, the agent runs one real-model session
on a real task, and the owner runs an independent pass. Both go into the
record before 0.40.6 is APPROVED.

```
npm install -g @vincemakes/kiso-code@0.40.6
kiso --version        # 0.40.6
```

A session opened before the install runs the old kiso — it says so after
its next turn. Exit it and resume it (`kiso resume <id>`).

## A. A gateway from plain `kiso`

1. For each gateway you use, once:

   ```
   kiso login --endpoint https://<the gateway's host>/<any path>
   ```

   Type the key at the hidden prompt (or pipe it in).
   - **Expected:** `stored an API key for https://<host> (••••xxxx) …`;
     the path is not part of what is stored.
2. `kiso auth`.
   - **Expected:** an `endpoint:https://<host>` row, masked.
3. Start plain `kiso` (no wrapper script), `/model`.
   - **Expected:** the gateway profiles are no longer `unavailable`; no
     row carries `ctx`.
4. Switch to a gateway profile and send one message.
   - **Expected:** it answers (or the gateway's own limit message, if the
     account is still at its weekly limit — that is the account, not kiso).

## B. Hidden thinking

1. With a thinking model, send a message; press ctrl+t while it thinks.
   - **Expected:** the thinking collapses to one italic `thinking…` line
     and no more of its text is drawn; the answer is unchanged.
2. Exit and start a new session; send a message.
   - **Expected:** its thinking is one line from the start
     (`thinking… · /think` once settled); `/think` shows the full text.
3. ctrl+t again.
   - **Expected:** the text is back, and stays shown in the next session.

## C. `/settings`

1. `/settings`.
   - **Expected:** `mode bypass`, from user config; each row says where it
     came from and how to change it; `thinking` says whether ctrl+t set it.
2. Type `/se`.
   - **Expected:** the menu offers `/settings`.
